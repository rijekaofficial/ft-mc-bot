# FunTime MC Bot

Параллельный поиск игроков по анархиям на сервере **play.funtime.su** с управлением через Telegram.

## Архитектура

```
┌─────────────┐     nick      ┌──────────────────────┐
│  Telegram    │──────────────→│   SharedState        │
│  Bot         │               │  (target_nick,       │
│              │←──────────────│   anarchy_queue)     │
└─────────────┘     result     └──────────┬───────────┘
                                          │
                    ┌─────────────────────┼─────────────────────┐
                    ▼                     ▼                     ▼
              ┌──────────┐         ┌──────────┐         ┌──────────┐
              │ Bot #1   │         │ Bot #2   │         │ Bot #3   │
              │ ir1skaa_ │         │ ir1skaa_ │         │ ir1skaa_ │
              │ ft_1     │         │ ft_2     │         │ ft_3     │
              └────┬─────┘         └────┬─────┘         └────┬─────┘
                   │                    │                    │
                   ▼                    ▼                    ▼
              ┌─────────────────────────────────────────────────┐
              │              play.funtime.su                     │
              │  /an101..114  /an201..228  /an301..325          │
              │  /an501..516  /an901..904                       │
              │  (87 анархий, распределяются между 3 ботами)    │
              └─────────────────────────────────────────────────┘
```

## Как работает

1. **3 MC бота** подключаются к `play.funtime.su` (оффлайн-аккаунты, пиратский сервер)
2. Отклоняют ресурс-пак и ждут 10 секунд
3. **Telegram бот** принимает ник игрока для поиска
4. 3 бота **параллельно** проверяют 87 анархий:
   - Каждый берёт следующую команду из общей очереди (`/an101`, `/an102`, ...)
   - Отправляет команду → ждёт 3 сек → читает **TabList** (список игроков)
   - Если ник найден → уведомление в TG → `/hub` → ожидание
   - Если не найден → берёт следующую анархию
5. Боты не пересекаются — каждая анархия проверяется только одним ботом

## Установка и запуск

### Требования

- **Rust nightly** (azalea требует nightly)
- Интернет для подключения к серверу и Telegram API

### Сборка

```bash
# Установите nightly Rust
rustup install nightly
rustup default nightly

# Соберите проект
cargo build --release
```

### Запуск

```bash
cargo run --release
```

Или с отладочным выводом:
```bash
RUST_LOG=debug cargo run
```

### Использование

1. Запустите бота
2. Откройте Telegram и напишите боту `/start`
3. Отправьте ник игрока (например, `Notch`)
4. Боты начнут параллельный поиск по 87 анархиям
5. При нахождении вы получите уведомление с номером анархии

### Команды Telegram

| Команда   | Описание                       |
|-----------|-------------------------------|
| `/start`  | Приветствие и инструкции       |
| `/status` | Текущий статус ботов           |
| `/stop`   | Остановить активный поиск      |
| *ник*     | Начать поиск игрока по нику    |
