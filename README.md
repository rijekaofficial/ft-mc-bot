# ft-mc-bot

Параллельный поиск игрока по анархиям **play.funtime.su** тремя ботами (mineflayer) с управлением из Telegram.

Stack: **Node.js + TypeScript (ESM)**, зависимость только `mineflayer` — Telegram реализован на встроенном `fetch` (long polling).

## Как работает

1. Три аккаунта (`ir1skaa_ft_1..3`, offline-auth, пиратка) заходят на сервер и **ждут 10 секунд**.
2. Дальше висят в хабе и ждут ник из Telegram.
3. При запуске поиска все анархии кладутся в **общую очередь** — каждый бот берёт следующую свободную, поэтому два бота никогда не попадают на одну анку.
4. На анархии бот ждёт спавна, собирает **весь tab-лист игроков**, сверяет с искомым ником и **сразу пишет следующую `/anXXX`** (без возврата в `/hub`).
5. Как только ник найден (или очередь кончилась / поиск отменён) — все боты пишут `/hub` и ждут следующий запрос.

## Анархии

`/an101–/an114`, `/an201–/an228`, `/an301–/an325`, `/an501–/an516`, `/an901–/an904` — 87 штук.
Bedrock-анархии (`/anXX`, две цифры) не используются.

## Запуск (Node.js 18+, TypeScript)

```bash
npm install
cp .env.example .env      # при желании поправить
npm start                 # компиляция в dist/ + запуск
```

Другие скрипты:

```bash
npm run build       # только компиляция в dist/
npm run start:built # запустить уже собранное, без пересборки
npm run dev         # tsx watch, запуск .ts без сборки
npm run typecheck   # проверка типов
```

`.env` читается самим приложением (`src/env.ts`), никаких флагов Node не нужно.

### Termux / Android

В Termux бинарники из `node_modules/.bin` часто падают с `tsc: Permission denied`
(нет `/usr/bin/env` и exec-бита), поэтому все скрипты вызывают инструменты напрямую
через `node node_modules/...`. Если что-то всё же не запускается:

```bash
pkg install nodejs git
cd ~/ft-mc-bot && npm install
node node_modules/typescript/bin/tsc -p tsconfig.json
node dist/index.js
```

Чтобы бот не умирал при сворачивании Termux: `termux-wake-lock`.

## Telegram

- прислать просто ник → старт поиска
- `/find <ник>` — то же самое
- `/status` — состояние ботов и прогресс
- `/stop` — отменить поиск
- `/list` — список анархий
- `/help` — справка

Ответ при успехе: на какой анархии сидит игрок и какой бот его нашёл.

## Структура

```
src/
  index.ts      — точка входа, Telegram-хендлеры
  env.ts        — чтение .env без зависимостей
  worker.ts     — один аккаунт: коннект, реконнект, переход на анку, сбор игроков
  search.ts     — параллельный поиск с общей очередью анархий
  telegram.ts   — Telegram Bot API на long polling, без зависимостей
  anarchies.ts  — генерация списка анархий из диапазонов
  config.ts     — конфиг из ENV
```

## Заметки

- `MC_VERSION` подстрой под текущую версию FunTime, если протокол не совпадёт.
- Ник ищется без учёта регистра; учитываются только игроки, видимые в tab-листе.
- При кике/дисконнекте бот сам переподключается через `RECONNECT_DELAY_MS`.
